# Informatics

Решения задач по информатике на языке **C**, сгруппированные по темам.

## Структура проекта

```
informatics/
├── condition/              # Задачи на условия
└── learning_a_programming_language/
    ├── Input_Output/       # Ввод и вывод данных
    ├── conditional_operator/  # Условный оператор
    └── loop_operator/      # Операторы цикла
```

## Технологии

- Язык программирования: **C**
- Компилятор: GCC

## Сборка и запуск

```bash
gcc task.c -o task -lm
./task
```
